# 🍺 BJCP 酿造游戏

&gt; 一个基于 BJCP 2021 啤酒风格指南的互动学习游戏。
&gt; 今天是我人生中做的第一款游戏。2026年6月5日。

---

## 三个模式

| 模式 | 适合谁 | 玩什么 |
|------|--------|--------|
| **学徒模式** | 刚接触精酿 | 认识原料，理解风格，慢慢酿 |
| **考试模式** | 想验证自己 | 判断风格、识别缺陷、参数匹配 |
| **创新模式** | 想搞点新东西 | 自由调配，看看你能创造出什么风格 |

---

## 为什么做这个

我最近在学 BJCP（Beer Judge Certification Program），一边学一边发现：光看文本很干，不如动手"酿"一遍。

这个游戏把所有风格参数、品鉴逻辑、酿造知识都塞进去了。你可以把它当成：
- 一个**学习工具**（如果你也在备考 BJCP）
- 一个**啤酒风格速查表**（117个风格，随时翻阅）
- 或者只是一个**好玩的游戏**（酿酒比消消乐有意思）
